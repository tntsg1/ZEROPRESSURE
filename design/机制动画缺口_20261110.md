# 机制动画缺口排查（2026-11-10）

起因：用户原话"冰船融冰……怎么突然消失……还有什么其他飞船是这种类型，只是画大饼玩法，但是动画一点没有。"

排查范围：`ships/*.json` 里全部特殊机制段（liner、waterball、boxbeam、sandwich、cold、drones、preloads/magnets/actuators/balance、immersion、drillstring、vaults、thermal、media、cryo、supercon、atmos、boiloff、ice、softshell、rails、nested、flywheel、bio、furnace、train、reactor、optics、munitions、dilution、sail、composite、tanknet、tether、rings、spine），逐个读对应脚本的 `_physics_process` 和事件函数，再核对有没有任何地方把这个状态画出来（脚本自带绘制、world.gd、art_*.gd、fx.gd 调用）。判断标准："状态变了，画面没有过程"——瞬间消失、瞬间变形、只有数字或文字在变。

工作量：小 = 一个文件、半天以内；中 = 一个新的 `*_fx.gd`，一天以内；大 = 要动物理或几何本身，或者要跨多个系统。

全部只做表现，不改机制数值和判定。下面"已补"的几项都是新增一个 `scripts/<机制>_fx.gd`，机制脚本里只加了"创建它"的 3 行。

## 四、液体用真实颜色（2026-11-10，用户："不同液体用它现实里的颜色"）

### 做法（`scripts/tank_fill_fx.gd`，只画）

- Jev：液体形态选"贴壁 + 中心气泡"（A 0.75，置信度 0.67）；罐体选"整罐半透明"（A 0.65 / 半剖 0.27，置信度 0.53，偏低：半剖要改静态缓存的设备美术，代价大，按 A 做）。
- 泊位无重力：液体润湿罐壁铺成一圈，增压气垫 / 蒸气是一个圆润气泡，缓慢漂移、轻微晃动；气泡边界就是气液分界（亮的弯月面 + 高光）。
- 体积一致：每个罐预先算好 16 档液膜厚度下的气泡（罐壁整体向内平移该厚度，凸形精确求交；再限制在一个随厚度缩小的圆内，所以小气泡是圆的，大气泡让液体在壁上成均匀薄膜），每帧按 气泡面积 = (1 − 实际量 / 满罐量) × 罐面积 在两档之间插值。实测画出的液体面积占比与系统液量占比最多差 3.7%（2%–98% 七档、13 艘船全部罐）。
- 抽取（体积在减少）：气泡被推离出口，液体聚到出口一侧（推进剂管理叶片），沿壁流向出口的流光 + 出口处涟漪。
- 低温液（液氢、LNG、液氦、液氮、液氧）：壁上起泡飘进蒸气泡；气泡里白色冷雾；罐壳外结霜。HG-170 按罐压沸腾：制冷时平稳，断冷压力升高时更猛，排放时最猛。
- 2D 画布在线性空间混合：0.1 的透明度看起来已是明显的灰，所以液体本体透明度压得很低。
- 性能：形状、表、霜在找到罐时算一次；每帧所有液体是一个三角形数组，弯月面是细线；屏幕外的罐跳过，两层（本体 + 发光）同帧共用一次形状计算。
