# A-暗1 炭黑 UI 推广清单（草案，待用户点头）

样板：船坞终端首页（scripts/terminal.gd 首页 + scripts/ui_kit/charcoal.gd）。
组件：Charcoal.ground / panel（厚度+阴影+按下）/ display（黑一级显示窗）/ led / knob / keycap / lip（橙色底条）/ section / groove / segments / slab / settle（落位动效）/ style_button（真 Button 的暗色键帽样式）。

## 推广思路
先改“共用底层”，一次覆盖大部分面板；再逐页精修布局（大编号、显示窗、旋钮只在合适的地方用）。

1. 共用底层（第 0 步）一次换掉，旧页面会在精修前先变成“炭黑但版式没调”的过渡状态，可以接受吗？

3. 现有的数据蓝（UiSkin.DATA，船坞剖面图里的设备口、价格标注）要不要一并改成白色？首页的小屏已改白，剖面图里的蓝还留着。
