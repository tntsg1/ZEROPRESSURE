设计游玩时长：40–60 小时主线成长，通关后可持续经营。

长期目标：玩家接手一座衰败的太空拆船厂，通过拆解报废飞船获取资金、设备和工业资源，逐步恢复整片太空工业港的运转，最终拥有能够建造、维修、改造和拆解巨型星舰的工业集团。原则：拆船是获取工业能力的主要手段，但赚钱绝不是唯一目标；玩家不需要每完成一艘船就等系统发下一份任务。

## 一、三个成长循环
- 短期 5–60 分钟：拆一艘船（调查 → 决策 → 拆解 → 资金与零部件）。
- 中期 1–8 小时：解决船厂当前瓶颈（缺电、缺设备、缺运力、缺资金、缺空间）。
- 长期 8–60 小时：恢复工业港并扩张（修基础设施 → 恢复贸易 → 产业链 → 重启转运环）。
不同阶段拆船追求不同：开局卖贵重设备换现金；中期找带完好发电模块的船；后期建转运环时大量收购金属含量高的货船。

## 二、永久存在、逐渐恢复的世界：零压港
六区 + 中央转运环，都永久存在，可观察损坏状态、修复进度、船舶流量。

| 区域 | 开局状态 | 修复后 |
|---|---|---|
| 拆船区 | 只有一座船坞能用 | 多船同时作业 |
| 动力区 | 主电网残缺 | 恢复高耗能设施 |
| 加工区 | 只有基础回收设备 | 废料加工为工业材料 |
| 拖船站 | 拖船损坏 | 自主获取远处废船 |
| 贸易港 | 航线稀少 | 多星区交易 |
| 中央转运环 | 严重损坏、封闭 | 巨型舰船靠泊、港口复兴 |

修复要有远景可见变化：动力区恢复后照明点亮；拖船站恢复后有船进出；贸易港恢复后物流增加。

## 三、拆下来的东西必须有去处
重要部件四种处理：出售（立即现金）/ 储存（等需求或价格）/ 维修（恢复功能提价或自用）/ 自用（装进船厂、机器人或运输船）。
例：灰鹭号主发电模块 G-01 可拆出、检测、翻修、接口适配后装到船厂备用供电，让缺电停摆的回收设备重启；急需现金也可直接卖掉，再租外部供电。
约束：回收设备不能毫无代价变成设施——要检查状态、接口兼容、供电/燃料、冷却、安装空间。

## 四、七阶段路线（时间仅为大致进度）
1. 0–2h 破产船厂：拆灰鹭号，修一项实际设施，第一次永久改变船厂。
2. 2–6h 重建物流：稳定废船来源，修拖船站，启动第二船坞。
3. 6–12h 工业化起步：冶炼与材料加工、储能与运输，卖原料还是做工业品。
4. 12–20h 自动化企业：验证过的工艺交机器人，玩家专管危险系统与高价值设备。
5. 20–32h 区域工业集团：贸易港、拍卖、长期协议、收购设施、竞争。
6. 32–50h 中央转运环复兴：分段施工，处理一艘作为核心材料来源的巨型殖民舰。
7. 50h+ 开放式工业帝国。
阶段切换靠真正修复基础设施、打通物流、改变瓶颈，不靠科技树。

## 五、灰鹭号之后五小时怎么玩
结算后不弹「三选一合同」，回到工业管理终端看实际问题：01 号船坞正常 / 02 号船坞缺供电 / 拖船站主推进损坏 / 加工厂冷却停机 / 旧债务。玩家自选先修哪项。
因果链示例：拆完灰鹭 → 修 02 号船坞 → 运力成瓶颈 → 修拖船 → 库存积压 → 修加工厂 → 能参与空间站重建。顺序不强制。

## 六、商业系统：持续运转的废船市场
三个市场：委托拆解（船主付费，有回收要求）/ 废船资产交易（买整船，可能买到烂船）/ 残骸回收（拖船取得回收权）。
四类机构：运输公司、保险与残骸拍卖、港口管理局、工业设备商与竞争船厂。初版只需几个有库存、预算、需求的机构按周期更新。
价格：实际售价 = 基础价值 × 成色系数 × 供需系数（+检测认证、运费、合同溢价）。供需变化来自公开可见的工业需求与库存，不是暗改难度。

## 七、四种经营压力
现金流 / 产能 / 设备可靠性 / 商业关系。压力来自玩家自己的扩张（2 坞够电、5 坞不够），不是系统惩罚；不出现一次失败就死局。

## 八、中期玩法：标准化作业 vs 非标准工程
标准化作业存入工艺库交机器人；新型号、受损反应堆、变形结构仍由玩家亲手处理。三种可兼营的企业专长：高速批量 / 精密设备回收 / 大型工程回收。自动化不跳过危险诊断，连接关系变化即暂停。

## 九、长期主线：中央转运环
五个子工程：恢复主电网 / 重建运输设施 / 修复环体结构 / 恢复工业控制 / 联合运行测试。每项与船厂经营挂钩（买新控制器或从军舰回收兼容设备；泊位合金自产或贸易购买），不要求拆指定船。
最终工程：约 800 m 废弃殖民舰，开局即可见，后期才有能力分段拆解，其结构与设备成为转运环最后一批资源；完工后大型星舰首次通过航道进港。

## 十一、落地：不重做拆船系统
新增持久化世界状态：CompanyState / StationFacility / Inventory / ShipMarket / ConstructionProject / ProductionSchedule。
关键接口 RecoveryZone：零件进回收区 → 分类 → 是否保留为完整设备 → 库存或出售 → 可成为建设资源。普通废料默认转材料；高价值件保留身份、成色、型号、兼容性。港口市场等按离散时段更新，不做万件实时物理。

建议顺序（五个可验证里程碑）：
1. 回收物用途系统（储存/出售/维修/安装）
2. 首个永久建设项目：修复 02 号船坞
3. 持续的废船市场
4. 基础工业经营（供电、仓储、加工、拖船制约）
5. 工业港复兴主线
第一个可玩版本：从一座船坞扩到两座，至少两种经营策略都能达成。

## 十二、原则
不让经营变成不断处理红色警告；早期解决过的问题后期应长期解决，新问题来自更大规模。

定位：从拆解一艘船，到重新激活一个星区的工业体系。
