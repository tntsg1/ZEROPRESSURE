## 反馈 2：交易行界面别扭、反人类

**用户原话（截图 6）：** “这个交易行还是感觉很差，感觉特别奇怪……居然里面的‘航运’是在右上角……我的挂单、交付记录，这个设计就是很反人类。”

**问题：**
- 版面东拼西凑：顶部一排按钮里混着星图航运、船市、自主挂单、暂停经营。
- 中间是报价列表，下面又塞了一条小标签栏，里面有“我的挂单 / 交付记录 / 工业客户 / 完整买卖行情”。重要内容挤在底部一小块里。
- “航运”是一个大功能，却只是右上角一个按钮。

**解决方法（建议）：** 交易行整页重排成“左侧大导航 + 右侧一整页”：

| 左侧导航 | 右侧内容 |
|---|---|
| **买** | 按货品看卖家报价，一行一个“买” |
| **卖** | 你库里有什么、谁在收、出价多少；一键挂牌（工业客户和加急单都在这里，加急置顶） |
| **我的交易** | 合并“我的挂单 + 交付记录”：一行一笔，状态写人话（挂牌中 / 已卖出已到账 / 运输中 / 已到库），每行最多一个按钮（撤回或去领货） |
| **航运** | 星图 + 在途货船列表，直接嵌在页里，不再是右上角按钮 |
| **船市** | 现在的船市页 |

- 顶部只留：可用资金和关闭按钮。“暂停经营”“完整买卖行情”“自主挂单”收进对应页的角落。

### 补充：用户给的参考——《三角洲行动》交易行（截图 8–10）

**用户原话：** “你实在不行，可以学三角洲的这些……比较市场价格是多少块钱，然后多少价格的有多少，多少价格有多少？这种是卖出去的，还可以自己定价格。”

**参考里值得学的三点：**
1. **买**（截图 8）：
   - 左边是一列货品大类；
   - 右边是大图卡片网格，每张卡写名字和价格；
   - 顶部有“我的收藏 / 最近购买”；
   - 页签只有三个：购买 / 出售 / 交易记录。
2. **上架**（截图 9）：
   - 左边一张**价格分布柱状图**：每根柱是一个价位，柱高是这个价位上在卖的数量，最低在售价标在顶上，你自己的挂单在柱上高亮；
   - 右边是物品图、出售数量滑条、参考价格、价格框（± 调价）、**预期收入（税后）**，以及一个大的“上架”按钮。
3. **出售二选一**（截图 10）：
   - **回收价**：立刻卖掉，便宜；
   - **交易行税后价**：上架等人买，贵一点。
   
   两个价并排摆出来，各配一个按钮。

**套到零压港（改后的反馈 2 方案）：**
- 页签改成三个大的：**购买 / 出售 / 交易记录**，另外加 **航运**、**船市** 两个。左侧是货品大类：未分选金属、黑色炉料、有色混合、钢坯、废船。
- **购买**：
  - 每种货一张卡，写最低卖价和现货吨数；
  - 点进去是卖家列表，标出“本港柜台 · 几十秒到”和“小行星带 · 货船几分钟”。
- **出售**，点一种库存货，弹出上架窗：
  - 左边是这种货的**价格分布柱状图**：簿上各价位在收多少吨（买单）、在卖多少吨（卖单）；
  - 右边是吨数滑条、参考价、价格框（±）、**预期到账（扣 2% 手续费）**，以及大的“上架”按钮。
  - 如果你的价格不高于某个买单，柱子上直接标“立即成交”。
  - 上面并排两个价：
    - **港务回收价**：港务局托底收，立刻到账但便宜，钢坯约为客户价的 70%；
    - **挂牌价**：自己定价，等人买。
  - 工业客户的买单和加急单就是柱状图里的高价柱，加急用橙色标出，不再单独一页。
- **交易记录**：
  - 合并“我的挂单 + 交付记录”，一行一笔；
  - 状态用人话写：挂牌中 / 已卖出已到账 / 运输中 / 已到库；
  - 每行最多一个按钮：撤回，或者去领货。
- 新增“港务回收价”属于新玩法（多一个托底出货口）。比例要你定，草图里先按 70% 画。

## 反馈 4：站体外观乱、装饰多、穿模，不硬核

5. 拖船站外的“拖船站外船位”虚线角框和点阵，像 UI 标记，不像实物。
6. 拖船站右边那几个圆头“子弹”形状（储罐 / 舱段），形状抽象、难看。

**解决方法（建议）：**
1. **外观全面清点，只留有真实用途的东西**：

   - 下一阶段长什么样，只在该区工程台的修缮页里预览；

4. **按正式工程设计重画剩下的部件**：

## 反馈 6：拖船站抽象、粗糙，不是想要的样子

**用户原话（截图 13）：** “这拖船站更是逆天！我想做的是一个拖船站，类似于港口那种，但是和贸易港不一样，是我个人那种、人家车库的样子。这做得真的很抽象，什么备件架、零件箱，怎么全是几何图形？很粗糙很粗糙，做得都好垃圾！”

**问题：**
- 拖船托架、备件架、零件箱、推进剂储罐、龙门吊全是方框和斜线，看不出是什么。
- 舱里没有一艘拖船，看不出这是“拖船的家”。
- 站外的“拖船站外船位”是 UI 角框加点阵（反馈 4 第 5 条）。
- 加工区的烟囱穿进本区底部（反馈 4 第 4 条）。

**规划里怎么说的，和你这次说的有一处要对齐：**
- 访谈 **Q44**（`E:\godot\zeropower\design\成长版本\G5-G7_工业港成长重设计_2026-10-22\11_入口与经营流程确认记录.md` 第十六轮）你当时选的是：“**露天拖船编队泊位为主**，多艘船出入港的规模感突出”。当时还写明：不把封闭维修机库当主体外观。
- 这次你说要“像港口，但和贸易港不一样，是我个人的、像车库那样”。
- 我的理解是两者合起来：**像自家车库排成一排的露天私人船坞**。不是公共码头，而是“我的船都停在这里，每艘有自己的车位”。

**解决方法（建议）：**
1. **主体改成一排私人泊位（“车库位”）**，从舱体伸到站外：
   - 每个泊位是一艘自有拖船的专属车位：地面编号和标线、系泊臂、充注臂（推进剂）、供电脐带、靠泊灯；
   - 泊位后墙是这艘船的“车库墙”：工具板、备件格、维护记录牌；
   - 没买船的泊位空着、灯暗，船位数随扩建增加（对应 Q44 的规模感）。
2. **停一艘真的拖船**：
   - 先放公司第一艘工业拖船，按船上设备那套画法画：船体剖面、推进器、牵引臂、缆绞车、推进剂舱、驾驶舱窗；
   - 它出去执行拖运任务时泊位真空出来，回来时靠泊（同一艘船、同一个航次，按 Q44 要求不用循环假船）。
3. **舱内只留真实整备功能**，每件按实物画：
   - 备件架：货架立柱 + 托盘 + 能认出的备件（推进器喷管、缆绳卷、电池模块）；
   - 零件箱：带盖周转箱，箱侧有标签；
   - 推进剂储罐：真实压力容器（同反馈 4 第 4 条）；
   - 龙门吊：有大车、小车、吊钩，能看出是在吊拖船部件。
   
   说不出用途的删掉。
4. **站外船位**改成实物（系泊桩、靠泊灯、地面标线），删 UI 角框。
5. 先出一张拖船站效果图给你看；同时请你确认“车库式私人泊位”是不是你要的意思。

- 舱外右侧有码头吊车、长桁架和下面一排方格（货运码头和泊位），没有任何标注和动作，看不懂。
- 货运区和上面的贸易区之间、和下面的船坞之间挤在一起，有穿模和压字。
- 大量橙色虚线框（“待修 · 阶段 2”“码头空地 · 未入库”等）。

**解决方法（建议）：**
1. **仓库按真实库存摆真实货物**，一种货一种样子，每堆标批号和吨数：
   - 钢坯：一捆捆方坯码垛（炉子炼出来的）；
   - 黑色炉料：压块成捆；
   - 有色混合：吨袋；
   - 未分选金属：料斗车；
   - 拆船回收的零件和设备：上托盘。
   
   买进来的货从码头入库口进来、拆船回收的从船坞那边进来，各自走到对应货位。卖掉就真的被搬走，货位空出来。
2. **吊车只在真搬货时动**，钩子上吊的就是那批货（同一批号）；没活就停在停机位，灯暗。舱外码头吊车同样只在货船真靠泊卸货时动。
3. **舱外码头讲清楚**：
   - 长桁架是码头栈桥，下面那排是泊位，加铭牌和靠泊灯；
   - 不对应真实功能的方格删掉；
   - 只有货船真的停靠时，泊位上才有船。
4. **拉开间距消除穿模**：按你说的，加长货运区和码头、拉开和贸易区、船坞的距离，同样纳入反馈 4 的“不许压进别的舱体”自动测试。
5. **去掉所有虚线**：
   - “待修”框按反馈 4 第 2 条删除；
   - “码头空地 · 未入库”这种待入库区域改成实线画的地面区（有地面标线和名牌），或者干脆只在有货等待时才显示货物本身。
6. 先出一张货运区效果图给你看，再做。

## 反馈 8：加急单能注意到；但专项训练课莫名其妙，灯照着空地

**用户原话（截图 15）：** “关于加急单，我可以注意到。但这个课程是什么鬼东西？莫名其妙弄一个空点，里面亮干啥？”

**加急单：** 你能注意到，**通过**，不改。

**问题：**
- 正在玩的是“专项训练 · 受力与运动 · 第 2 课 锁轨货物：开门、解锁、让它滑出来”。你不知道这课从哪来、为什么要上。专项训练是开某些业务前的强制资质（七门专项训练），但进课前没讲清楚“为什么现在要上这门课、上完解锁什么”。
- 船坞顶上一束聚光灯斜照到船坞中间的空地上，那里什么都没有。
- 课里的 SP-LOAD 图纸标着“出厂图纸 · 仅代表原始设计”，和货箱、轨道零件的名字（SWP、K-B、AP、G-ACC、TN-1、LK-1…）挤在一起，像调试标注，看不懂。

**解决方法（建议）：**
1. **进课前讲清来由**：
   - 每门专项训练开始前给一张卡：
     - “你要做 ××（例如：接含锁轨货物的合同）需要这门资质”；
     - “这课教什么，3 步”；
     - “上完解锁 ××”。
   - 只在你主动点“开始训练”或接到需要它的合同时才进课，不会无缘无故出现。
   - 要先查清这次是怎么进的课。如果是被引导或主线自动塞进来的，改成先问你。
2. **聚光灯只照真东西**：
   - 灯跟着当前步骤的目标走（这一课就照轨道尽头的闸门 GATE、锁 LK-1 和货箱）；
   - 没有目标就关灯，不再照空地。
3. **课里的标注减到“这一步要碰的那个东西”**：
   - 零件代号只在近看或开测量工具时显示；
   - 当前步骤的目标用名字写清（“轨道锁 LK-1”）并高亮；
   - “出厂图纸”那行字缩小放到角落。

## 反馈 9：船市界面太拉——没有船的图，信息堆太多

**用户原话（截图 16）：** “这个 UI 也做得太拉了，根本看不到任何关于卖家（卖的东西）的图片。而且做得特别复杂，跟真的一样，太过复杂，完全没有必要。我不是给你例子了吗。”（例子 = 反馈 2 补充里的《三角洲行动》交易行）

**问题：**
- 左边挂牌是一长列纯文字，每行塞满编号、船型、长度、星站、价格和评级，没有一张船的图。
- 右边详情从上到下一长串：
  - 卖家声明、评级、机构记录；
  - 两种检验、拖运 Δv；
  - 定金、还价、买下。
  
  全是同样大小的字和按钮，看不出重点。

**解决方法（按三角洲例子改）：**
1. **挂牌改成大图卡片网格**（像三角洲的物品格）。每张卡：
   - 船的侧视图：用游戏里这艘船的真实图纸渲染缩略图，就是你拆的那种船；
   - 船名；
   - 一个大字价格；
   - 评级几颗星；
   - 一个小标签：“在 ×× 星站 · 拖回约 3 分钟”。
   
   左侧加一列分类：按船型大小 / 按价格 / 我的船。
2. **点卡片弹出详情窗**，只放要紧的：
   - 左边：大幅船图，检验查出的隐患直接标在船图对应位置上；
   - 右边三块：
     - 价格对比：要价 vs 经纪估值；
     - 卖家说法 + 评级：一句话、一行；
     - 一个大的“买下并拖回 · 合计 $”。
   - 两个检验按钮做成船图下方的两个小按钮（结构 / 系统）。
   - 还价、保留报价、拖运 Δv、机构记录收进“更多”折叠。
3. **“我的船”页**：
   - 也是卡片，带船图和状态（拖运中 / 在港 / 已拆 / 已转售）；
   - 转售做成和反馈 2 一样的上架窗（价格分布 + 自定价 + 预期到账）。
4. 和反馈 2 的交易行一起出版面草图，你选完一起做，两边风格统一。
