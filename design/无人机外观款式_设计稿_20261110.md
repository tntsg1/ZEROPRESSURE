- 严格惯性：加速 → 尾焰；刹车 → 反推喷口朝前；侧推 → 对侧喷口；火焰长度按真实加速度（同一套 `thrust` 换算）。
- 工具颜色仍然是玩法信息：光圈镜头颜色、工具头（激光/抓钩/测量/扳手/回收）全部沿用原版画法，强调色只用在灯带、涂装、指示灯上。
- 细节开关 `lite`（屏幕上太小时省掉亚像素细节）、出舱“蓝图描边”启动动画、受击闪边、冲刺残影都有对应外轮廓。

## 阶段二计划（等点头）
1. 存档：`Career.data["drone_skin"]`（当前款）+ `"drone_skins_owned"`（已买列表，默认含 arrowring），旧存档读不到就是原版。
2. 购买：船坞终端“无人机升级”页加“机体外观”分区，左边转动样机，右边价格/余额，Enter 买；配装页加一行切换（← → 换款，样机预览）。
3. 接入：`drone.gd` 的 `DESIGN` 改读当前款，`Art.draw` → `Skins.draw`，喷口粒子 → `Skins.jets_world`，残影/受击闪边 → `Skins.hull`，核心辉光 → `Skins.core`；`look.gd` 头灯颜色/光锥宽度/射程按款；船坞、港区、录像回放、结算、图鉴插图里画无人机的地方统一走 `Skins.draw`。
4. 声音：单次音（抓取、出舱）通过 `sfx.play(..., pitch)` 已有参数传音高；**推进循环音的音高在 `sfx.gd` 里算，任务约束不能改 `sfx.gd`**，所以循环音先留占位（不变），需要用户同意在 `sfx.gd` 加一行读当前款的音高系数才能做。
5. 性能：凹多边形（各款机身）现在每帧三角化，接入时改成首帧缓存三角形索引；目标和原版持平，用现有性能测试同镜头对比。
6. 中英文字：款名、介绍、按钮文字中英都写，中文为占位稿，玩家看到的文字不写“机器人”。
