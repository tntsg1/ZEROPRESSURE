# MF-126「熔脊」全新方案 R2

> 126 m · 船载分选与材料再加工厂。待审，未入游戏。

## 独立设计任务

停机不等于冷却完成，必须保持换热通路，先处理输送线再取炉芯。

## 外形如何服务用途

前置收料口 / 厚隔热炉顶 / 后部换热设备与重主机。各设备必须有支撑、固定件和可到达的检修面；不以一个抽象图形替代整个工作船体。

## 六个结构点

1. 前置分选进料口
2. 封闭操作驾驶室
3. 厚壁隔热炉顶
4. 可整体吊出的炉芯
5. 余热与冷却回路
6. 双换热泵组

## 危险与读数

- 炉芯停机后仍有余热。
- 冷却回路不能过早断开。
- 进料机构仍可能有机械预载。

## 玩家操作顺序

1. 停止输送 → 确认锁止与余热
2. 保持换热 → 拆料道和外围设备
3. 冷却达标 → 整件吊炉芯 → 主壳

## 收益与成长

- 200 m 船坞 / 目标 40–55 分钟
- 炉芯、分选机与换热机组保完整
- 热控升级与重载抓钩解决不同瓶颈

工具：余热扫描 / 临时换热 / 重载吊运。规划约 210 件，数量仅作分件预算，不是已实现统计。

## 接入前验证

1. 每个关键节点都能用已有或明确标注的新操作处理。
2. 整件设备有设备口和吨位约束；危险介质分路交付，壳板进入金属回收口。
3. 状态改变后同步更新读数与视觉，不通过隐藏脚本自动完成整船拆卸。
4. 新机制先验证：停机不等于冷却完成，必须保持换热通路，先处理输送线再取炉芯。
5. 测完整船、半拆、碎片密集与设备转运四种状态的帧耗时；保留图形细节。
6. 价格与时长在原型里验证后再进入合同池；不直接沿用旧十艘的平衡数据。
