## 1. 这一批和第一批的区别

第一批 12 艘的骨架基本是「一根水平船体 + 若干舱段」：TUG、S-09、POD、GR-7、H-22、M-14、FR-26、MED-47、VT-80、PS-12、PT-34、ARK-01。差异主要在舱内系统、尺寸和危险类型。

第二批刻意**从结构原型上换掉水平船体**，每艘换一个维度：

| 换掉的维度 | 船 |
|---|---|
| 船体不是壳，是货柜 | CF-90 蜂巢 |
| 船体不是壳，是一张薄膜 | SA-200 纸鸢 |
| 船体不是壳，是一坨冰 | IC-120 冰山 |
| 船体不是壳，是一根系绳 | TB-180 连星 |
| 船体不是壳，是四个气囊 | IH-55 河豚 |
| 船体不是一条，是两条 | CH-110 书夹 |
| 船体不是一条，是七节 | MT-140 蜈蚣 |

## 3. 新机制分组（实现时可以共用一套底层）

| 机制族 | 船 | 要做什么 |
|---|---|---|
| 张力 / 索网 | SA-200、TB-180、CH-110、IH-55 | 一根索/带/梁受拉，剪断后载荷重分配；所有张力点可测 |
| 角动量 / 陀螺 | TB-180、MD-160 | 旋转刚体、飞轮、消旋；切割释放切向速度 |
| 载荷 / 承力路径 | CF-90、CH-110、MT-140 | 箱体/梁/联轴器承力，按顺序卸载，否则失稳 |
| 软壳 / 相变 | IH-55、SA-200、IC-120 | 非刚性壳体：塌陷、撕裂、融化和再冻 |
| 辐射 / 热 | NR-95 | 剂量场、阴影、热件、衰变热 |
| 单舱 / 火灾 | MY-48 | 一个压力容积、富氧、闪燃 |
| 透空 / 开放结构 | MD-160、CF-90 | 没有外壳，工具可达，但结构裸露、危险在外 |

## 4. 建议接入顺序

这批不按现有阶段 3–6 硬插，建议做成 **200 m 泊位后的「异形船专线」**，由一个新经纪人（回收站深区）发高价专单；也可以拆成高阶市场随机单。

1. **第一批（80–120 m 泊位就能做）**：MY-48（教学：单舱 + 火）→ IH-55（软壳）→ CF-90（承力货柜）→ NR-95（辐射）。
2. **第二批（200 m 泊位）**：MT-140（铰接/总线）→ CH-110（夹持/跨接梁）→ MD-160（飞轮）→ IC-120（冰）。
3. **压轴**：SA-200（薄膜）→ TB-180（系绳/角动量）。这两艘的机制最极端，放在最后。

## 5. 审稿时请重点看

1. **外形是否真的一眼不同**：不要又是「一根船体换舱段」。
2. **新机制是否值得做**：每艘只带 1–2 个新系统，且能和现有测量/切割/抓钩/维护工具接上。
3. **是否可测**：所有事故都要能提前测出来（剂量、张力、载荷、裂纹、氧浓度、转速）。
4. **是否有安全路径**：机器人能按规程拆完；不允许只有「运气」才能过。
5. **价值是否合理**：非金属船（纸鸢、河豚、冰山、露珠）的价值要落在设备/内饰/水，不落在外壳。
