## 和核爆的区别
核爆：全屏白闪、火球、热碎片壳、逐区冲击镜头、红橙色。湮灭：不全屏白，只有针尖星和一条细光壳；没有火球和碎片；靠细线画出来的物理（磁场线、螺旋径迹、线稿余辉）；冷白/青蓝/淡紫，只在最后出几粒橙。镜头只围绕储存阱推拉，不做逐区巡游。

## 性能（1080p，本机，同时有十几个 Godot 测试进程在跑）
- 整段 597 帧：平均 15.99 ms，P95 17.01 ms，P99 17.31 ms，最大 22.24 ms（被 vsync 锁在 16.6 ms 附近）。
- GPU：P50 2.39 ms，P95 3.26 ms，最大 3.64 ms；渲染 CPU P50 1.28 ms，P95 4.52 ms。
- 分段 P95：失约束 16.8 / 坍缩 17.5 / 湮灭 16.9 / 粒子谱 17.0 / 余辉 17.0 / 卡 17.0 ms。
- 做法：径迹在工作线程里一次性算好，烘焙成一个网格（约 32 万顶点），着色器 `scripts/anni_tracks.gdshader` 按时间决定每段长没长出来、头部亮珠和衰减，按缩放保持屏幕像素线宽，另画一遍宽淡的光晕；每帧 CPU 只改几个参数。扭曲/反相/压暗/线稿余辉都在原有后处理 `scripts/look_post.gdshader` 里，用 a_* 参数，全为 0 时不影响原画面。
- 首次画新材质会编译管线（实测 109 ms 和 39 ms 两次卡顿）：加了 `warm()` 预热，预热后这两处消失。第 2 段会在 AX-40 进场时调用 `prebake()` + `warm()`（烘焙在工作线程约 1.7–2.4 s，不阻塞主线程）。
