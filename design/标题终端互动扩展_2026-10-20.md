# 标题终端互动扩展

用户反馈上一版互动集中在工程图，页面其他区域反应少。这次保留工业终端布局，将八个原有区域接入实际操作，每个区域都有缓动边框和页脚操作提示。

| 区域 | 鼠标操作 | 结果 |
| --- | --- | --- |
| 游戏标题 | 悬停、单击 | 标题边框展开；重播分层入场，菜单无需等待 |
| 系统就绪 | 悬停、单击 | 重新扫描真实图纸，状态显示扫描中 |
| 全长尺寸尺 | 移动、单击 | 映射整艘船的横向坐标，详图同步追踪；单击锁定 |
| 结构详图 | 按住拖动、滚轮 | 按实际放大倍率平移；缩放倍率限制为原始详图的 1–3 倍 |
| 接口地图 | 移动、单击 | 预览区域、定位并锁定该处结构 |
| 图纸图层 | 单击循环 | 完整图纸、船体结构、作者配置的管线路径 |
| 接口标记 | 单击 | 开关所有实际控制点标记，显示真实数量 |
| 作业状态 | 单击 | 打开原有存档管理 |

页面留白中的分隔线和顶边也会跟随鼠标响应。所有功能沿用现有精简/关闭动画偏好；菜单、存档、设置、开发者模式仍拥有各自输入优先级。

船体、管线与接口十字均在载入时建立缓存网格，交互不会重复解析船体或重建几何。检视窗口始终使用真实船体坐标，未添加虚构图纸或统计数据。

验证入口：`tests/title_motion_check.gd` 的扩展交互检查，以及 `tests/title_terminal_check.gd` 的既有菜单检查。实机录制用模拟鼠标驱动原生界面，保持测试存档隔离。

本次实机检查：26 项动态交互和 23 项菜单回归通过，日志无脚本或 shader 错误。GTX 1080、D3D12、1280×720 活动检视样本平均 1.72 ms/帧，仅代表本机标题页。`proofs/title_terminal_interactions.gif` 为 20 fps、11.5 秒的原生渲染记录。独立 release 体验版为 `build/ZeroPressure_全区互动.exe`，另有无头启动退出检查；鼠标操作和视觉验证在源项目完成。
