# 给写作 AI 的提示词：《零压拆船厂》成长体系台词（G1 / G2）

> 用法：把从「你要写的是」到文末的全部内容，原样交给写作 AI。它交回的 JSON 直接发给开发这边，合并进 data/copy.json。

---

## 你要写的是

一款 2D 太空拆船游戏《零压拆船厂 ZERO PRESSURE》里的一批短台词。全部是船坞工程师**梁工**在无线电里说的话。只写下面「待写清单」里的编号，不要增加编号，不要改编号。每一条都要中文；英文可写可不写（不写由开发翻译）。

## 世界与基调

- 近地轨道上漂着一个世纪的退役船，拆船是这里最赚钱、也最容易出人命的行当。行规写在每个泊位的门框上：先归零，再动刀——压力归零、电压归零、温度归零，最后让船本身归零。
- 锈环站（RUST RING）是一座低轨拆船站。玩家接手其中的 BERTH 07 泊位。卡戎轨道回收（CHARON ORBITAL SALVAGE）是经营公司：发合同、收合同费、放贷款，不关心船为什么出事，只关心回收率。
- 玩家从不露面，坐在站里通过远程无人机 R-02 工作。
- 基调：安静、克制、工业。没有反派。不煽情，不喊口号。

## 这一批台词的背景：破败的船坞

- 玩家接手的 BERTH 07 是一座半残的船坞：两盏泛光灯只亮一盏还在闪，甲板灯稀疏，边缘牵引场只有一半力；碎屑网上有个洞，三分之一的碎块漏掉；熔炉只有小火，吞一件废料要三倍时间。另外十三项设施（搬运无人机、第二设备回收口、可移动炉口、缓冲平台、作业区管理、碎屑网升级、第二台搬运机、回收机械臂、重型起重机、泊位扩建四级）都是坏的，船坞里对应位置画着虚线残骸和「待修」牌。
- 修船坞靠拆下来的东西：完整送进设备回收口的**供电**设备（发电机、蓄电池、电容、燃料电池、配电柜）、**热工**设备（冷却泵、散热器、环控、生保）、**驱动控制**设备（发动机、推进器、导航电脑、控制台、液压缸、绞盘、机械臂）会进入零件仓库而不是当场变现；进熔炉的金属按吨算**结构**。用零件修付标价一半，纯现金修付全价。仓库里的零件也可以卖掉换钱。
- 公司提供贷款：开局不欠钱，但额度第一天就开放（见习 5 万，随声望升到 100 万），每单扣分期和利息。
- 修好一项后，玩家下次回船坞会看到三秒施工：火花、闪光、「修复完成」牌，灯亮起来。
- 另有三件**部署工具**：牵引锚（打在船体上，整段切离后绞盘把整段拖进熔炉槽）、独立泵（贴在舱壁或储罐上自己抽，不需要接口）、监测探头（留在测点上，读数常亮、变化时报）。两项**工程成果**：「整段分离」（6 吨以上的整体进回收口）、「压力设备回收」（出厂带压的储瓶完整进设备口），达成后永久开放对应工具型号。带出去的工具可能丢：毁机会掉落，留在船上不收回会随零件进炉。
- 三个可反复接的**修缮任务**：A 雨燕（拆蓄电池、燃料电池、配电柜，修照明）；B 灰鹭（借牵引锚，整段送炉，修碎屑网）；C 灰鹭（接口被阀门封死，借独立泵贴壁抽空，拆冷却泵和散热器，修熔炉主火）。

## 会说话的角色

**梁工**（BERTH 07 的船坞工程师）。作者原剧本里的人设，必须遵守：
- 资历：从业二十多年的船体回收工程师。
- 性格：务实、冷静、偶尔讽刺，不喜欢无意义的废话。
- 说话方式：短句、自然口语，不用夸张的科幻术语。
- 对玩家的态度：不把新人当傻子，但绝对不允许他忽视危险。
- 特点：经常把昂贵的设备损失换算成钱。
- 不会一直说「干得漂亮」「太棒了」。对这座破船坞有感情，但不说出口。

作者剧本里梁工的原话，作语气参考：
- 「不确定的东西，先查清楚再动。」
- 「第一笔收入，够买几杯咖啡。先别急着发财，接下来还有正事。」
- 「零倒是零。可它测的是哪儿？」
- 「要是把完整模块直接烧成废铁，老板估计比电容炸了还心疼。」
- 「行，至少你没把船坞一起拆了。」
- 「第一次接正式合同就做到这个程度，挺少见的。老板看了应该高兴。就是别指望他给你涨工资。」

## 硬性规则

1. 每句不超过约 40 个汉字（念出来约 12 秒）；要两句的用编号 _1、_2（清单里注明了允许几句）。
2. 不要直接教玩家操作（不要写「按 6 放探头」「去终端点修」），只说人话。
3. 不要用「太棒了」「干得漂亮」「让我们」「值得一提的是」这类话，不要感叹号堆叠，不要排比。每句都要像一个人随口说的，不像文案。
4. 不要新增人物，不要提 KX-0 和灰鹭号事故的真相。
5. 钱和设备可以具体：梁工会算账。
6. 终端系统文字不在这批里，不用写。

```json

  "L_parts_first": ["这台发电机先放仓库。你再看一眼船坞那盏灭掉的灯。", ""],
  "L_berth_broken_1": ["……", ""],
  "L_berth_broken_2": ["……", ""]
}
```

不要在 JSON 外面加解释。
