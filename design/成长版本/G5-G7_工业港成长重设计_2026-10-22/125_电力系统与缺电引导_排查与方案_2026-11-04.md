## 二、整改方案（推荐）

### A. 状态说真话（R1、R4、R9）
1. 炉次的现场状态拆成：仓库有料 / 叉车出库 / 运输中 / 炉口有料 / 炉内有料（固 / 液）/ 出钢中 / **钢坯冷却中（还要约 N 秒）** / 运回仓库 / 空炉。引导、炉台、炉体标签、动力区共用这一份判断。
2. “加热熔化中”只在**炉内有料且实际功率 > 0** 时出现；实际 0 MW 时写真实原因：空炉 / 没分到电（被谁挤掉）/ 欠电费 / 新炉次被延后 / 送料未到。
3. 分配功率与实际功率分开写：“分到 4 MW · 实际在用 4 MW”；百分比写成“供电 17%（4 / 24 MW）”。
4. 卡住超过一段时间（如运输受阻 30 秒）给恢复入口（重试 / 让开 / 联系现场）。

### B. 第一次真实缺电时的引导（R2、R3、R7）
按外部要求的六步：问题发生处提示（需要 / 分到 / 实际 / 影响）→【查看原因】【稍后处理】→ 选查看才带去动力区 → 动力区先讲这一次（电从哪来 → 多少 → 谁在用 → 谁不够 → 能怎么办）→ 玩家选岸电 / 调优先级 / 修动力区 / 先不管 → 回到设备看实际结果，问题真没了才算完成。
- 触发：真实 short 且影响当前作业的负载（电弧炉在熔料、激光在切、传送带、船坞熔炉）；空炉、未送料、冷却中不算。首船补贴线路不触发。
- 替换现有的动力区“认位置”导览；“稍后处理”不丢主线、不反复打断（同一原因 5 分钟内不再弹）。

### C. 动力区首屏（R4、R5）
港口电力：正常 / 紧张 / 不足 → 自有供电（破旧主机组，6 MW）当前用 / 容量 → 岸电当前用 / 上限 / 价格 → 受影响的设备（需要 / 分到 / 实际 / 状态）→ 原因 → 可做的事。单线图、仪表、曲线、手动调度放第二屏。每台负载标：已建成 / 工作中 / 用电中 / 缺电受影响 / 空闲。

### D. 缺电的处理办法在设备旁边就能做
炉台和船坞 HUD 的缺电提示里直接给：接岸电（价格、上限）、把这一组调到最前（影响谁）、去动力区。不用每次跑去动力区。

### E. 教程总览（R6）
M01–M08 按现在的真实流程重写：钢锭从哪来、送料、通电熔化（自动控温）、取样出钢、冷却运回、分选化验、电不够怎么办。

### F. 送料（R8）
沿用 124 号待定的四个方案（推荐“提速 + 在路上就能送”）。

## 四、验收（按外部要求的 10 个场景）
新存档无缺电不被拉去动力区；第一次真缺电的提示与选择；去动力区处理后数字与结果一致；分配≠实际时说明原因；空炉 / 未送料 / 冷却中不误导；岸电、优先级、修动力区三种办法各自的条件、费用、实际影响；拆船与炼钢同时运行真实共享电力；拒绝或延后引导不丢任务不反复打断；存档读档后一致；长时间无进展给原因或恢复入口。自动测试之外需要真人从新存档试一次。
