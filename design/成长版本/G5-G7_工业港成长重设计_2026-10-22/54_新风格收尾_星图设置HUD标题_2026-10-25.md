# 54 新风格收尾：星图、设置、现场 HUD、标题

日期：2026-10-25。依据：用户“其他所有 UI 都要换成这个 UI”（51 号）后，剩下没换完的四处；用户 10-25 让我继续完成。状态：设计已写，实现中。

## 做法

1. **现场 HUD 的所有手绘框**（主线卡、合同卡、右上小条、左下状态、结算、提示条、工程台叠层等）共用 `UI.panel`。不逐个改，直接把 `UI.panel` 换成新风格：
   - 深色圆角（半径 14）底，带一点透明（盖在场景上要看得清字，底色用 `UiSkin.BG0`，不透明度 0.86）；细白描边 8%；
   - 被选中 / 悬停：描边转暖橙、左边一条圆头强调线；
   - 出现动画：原来是“亮笔沿方框描边”，改为圆角框淡入 + 轻微上浮（动画等级 0 时直接出现）。
2. **设置页**：黑色遮罩换成新风格底（渐变 + 暖光 + 鼠标跟随光）；每一行是圆角玻璃条，悬停或选中时浮起、描边变暖橙；音量条改为圆角进度条（暖橙填充）；改键列表同样用圆角条。
3. **星图**：底换成会动的新风格底；地图区域放进一块圆角“屏幕”；太阳、港口、货船改用统一的暖橙 / 青色；货船未飞的那段航线由虚线改为淡色实线（用户不喜欢虚线）。
4. **标题画面**：标题终端的菜单已在 51 号换成玻璃按键；这次把信息框和底改为新风格的底与圆角框，原有的倾斜卡片动画保留。

## 八条法则对照

一致性：全部界面同一套圆角、颜色、动效；反馈：悬停与选中都有浮起与描边变化；减轻记忆负担：设置里每行当前值就地显示。
