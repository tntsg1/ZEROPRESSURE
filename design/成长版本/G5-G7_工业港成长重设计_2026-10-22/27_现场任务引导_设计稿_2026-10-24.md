# 27 · 现场任务引导

日期：2026-10-24。用户试玩反馈（附终端首页与分选台截图）：“像这 4 个我点击一个就要有那个引导，比如说我化验为什么还有这个炉子，太复杂了，至少要有引导。”

## 问题
- 点“现场”类事项只在终端里显示一句位置说明，玩家关掉终端后不知道往哪飞、到了按什么。
- 船坞地板下面分选线、熔炉、化验位挨在一起，周围还有两块大的机器读数牌（预处理线、VIM-07 熔炉），不知道哪个是哪个、为什么化验旁边有炉子。
- 一件生意要连着走分选 → 化验 → 炉台 → 客户，每台机器又有好几步，之前的“经营开工指引”是静态翻页文字，不够。

## Jev（2026-10-24）
| 问题 | 选择 | 概率 | 置信 |
|---|---|---|---|
| 引导形式 | A 现场任务引导：关终端，HUD 步骤卡 + 屏幕边缘箭头 + 目标工位脉冲框和一句用途；打开机器面板后该按的按钮高亮；按真实状态自动推进；可随时结束 | A 1.00 | 1.00 |
| 做完一件后 | A 自动接下一件相关的事，卡片说明为什么，可随时停 | A 0.94 | 0.91 |
| 读数牌太多 | A 引导期间淡化与当前步骤无关的机器读数牌，只突出当前工位 | A 1.00 | 1.00 |

## 做什么（`scripts/guide.gd`，挂在船坞场景）
1. **五种任务**，每种的“现在该做什么”都从真实状态算出来，不靠计数：
   - **分选**：飞到分选台 → 按 E → 选吨数按“把仓库废料送到分选机” → 等原料运到 → 按“启动分选驱动” → 等粉碎磁选 → 等两路产物回仓 → 完成。
   - **化验**：飞到化验位 → 按 E → 按“定级 …” → 等光谱读数（显示百分比） → 完成（合格 / 不合格写明）。
   - **炉台**：飞到炉台 → 按 E → 按“把仓库炉料送到炉口” → 等运到 → 功率填 100 按“设置功率” → 按“开始装炉” → 等熔化（显示炉温 / 出钢温度 / 未熔吨数） → 按“测温取样” → 等探头收回 → 按“倾炉出钢” → 等钢坯冷却回仓 → 完成。
   - **客户发运**：卡片上一键打开交易行“工业客户” → 承接 / 填吨数发运 → 等客户收到付款 → 完成。
   - **买炉料**：卡片上一键打开交易行“黑色炉料 等级 1” → 点一家的“购买” → 等货进仓 → 接炉台。
2. **点事项就开始**：终端首页“需要你决策的事项”里分选 / 化验 / 炉次 / 客户缺口 / 可开炉这几条，点一下关终端、开引导。客户缺口按实际库存选起点：有钢坯 → 客户发运；有合格炉料 → 炉台；有可化验料 → 化验；有未分选金属 → 分选；都没有 → 买炉料。
3. **做完自动接下一件**：分选 → 化验 → 炉台 → 客户发运；卡片顶部写“完成：…，接着：…（原因）”。
4. **HUD**：屏幕上方中间一张步骤卡（任务名 · 第几步、现在做什么一句、补充一句）+“结束引导”按钮，需要时还有一个动作按钮（打开交易行）。目标在屏幕外时边缘箭头指过去，在屏幕内时目标工位画脉冲框、写名字和一句用途（例：“化验位：读样品定等级，和炉子无关”）。
5. **按钮高亮**：机器面板 / 交易行打开时，当前该按的那个按钮加橙色脉冲边框。
6. **淡化读数牌**：引导期间不画预处理线和 VIM-07 熔炉的大读数牌（机器本身照画），结束后恢复。
7. **存档**：当前任务记在生涯里（`guide_task`），去拆船回来接着引导。

## 不做
新手训练课程本身；台词（引导卡是界面说明文字，不是角色台词）。

## 自动验收 `tests/guide_check.gd`
1. 点“仓库有 X t 未分选金属”事项：终端关闭，引导任务为分选，第一步“飞到分选台”，箭头 / 目标是分选台。
2. 无人机到分选台 → 步骤变“按 E”；打开面板 → 步骤变“送料”，“把仓库废料送到分选机”按钮被高亮。
3. 引导期间 `Guide.quiet` 为真（读数牌不画），结束后为假。
4. 分选完成后自动接到化验；化验完成（合格）自动接到炉台。
5. 炉台步骤按炉况推进：功率 0 → “设置功率”；有料未装 → “开始装炉”；熔化中显示炉温；可取样 → “测温取样”；可出钢 → “倾炉出钢”（用炉体状态夹具，不跑整炉）。
6. 客户缺口事项按库存选起点；买炉料任务的动作按钮打开交易行到黑色炉料等级 1。
7. 存读档：任务跨场景保留；“结束引导”清掉。
8. 截图：步骤卡 + 箭头、分选面板按钮高亮、化验进行中。

## 实现结果（2026-10-24）
**状态：已实现并通过自动验收，待用户试玩。**
