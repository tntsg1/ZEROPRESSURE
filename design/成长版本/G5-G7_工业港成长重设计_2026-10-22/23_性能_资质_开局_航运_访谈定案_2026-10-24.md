# 23 · 性能、资质流程、开局与轨道航运：访谈定案

日期：2026-10-24。来源：用户 grilling 五轮（Q1–Q33）逐题作答。本稿是后续五步的设计基准；每一步开工前仍按规则写各自的一页设计稿（24 号起）。状态：**定案，待用户确认后开工**。

## 用户原话要点
- “目前性能表现很差，玩得特别卡。在不降低目前画质的情况下，你优化一下性能表现。”
- 需要资质的船：去掉“需要资质”提示，点进去直接开始资质，完成后直接接合同。
- “开始不是继承这个废船厂……我最开始是从小行星带回收废船，然后卖材料开始起家，然后越做越大。”
- “我买东西，难道不是要显示有个飞船从地图上出发，然后按照现实的轨道转移，然后停泊在港口，然后无人机去港口领，这些都是要硬核的。”

## 实测（2026-10-24，tests/perf_now.gd，屏外窗口、关垂直同步）
空船坞 50 ms/帧（最差 73）、缩远 46、港区全景 43；每帧约 2,400 次绘制调用、7,200 个绘制对象。拆船合同（GR-7、FX-70）约 7–8 ms。卡顿集中在 10-24 加的港站绘制。

## 定案
| 编号 | 决定 |
|---|---|
| Q1/Q2 | 只做性能，画面不改；目标 1080p 60 帧（≤ 16 ms）。静止港站画面缓存、光晕合批、看不见的室内不画；先空船坞与港区，再复查拆船与终端 |
| Q26 | 验收：改前改后空船坞、港区全景、六区室内、终端首页截图逐像素对比几乎一致，且帧时间达标 |
| Q3/Q4 | 保留现有专项课（2–4 分钟练习）；需要资质的合同卡点一下直接进课，去掉“需要资质”提示行；课后弹配装页再直接开工；普通合同卡保留“先选中、再确认” |
| Q5/Q6 | 开局先改说法与第一批合同；完整“小行星带序章”随航运一起做。顺序：性能 → 资质 → 开局说法 → 轨道航运 → 加工区搬家 + 仓库可见（Q33 一步一交，问题攒到最后） |
| Q19 | BERTH 07：荒废多年，你凭回收权申请到使用权，不花钱，一切都是坏的 |
| Q20 | 开局几艘是你的拖船从小行星带拖回的**无主漂流船**，材料全归你；之后受托与无主两种都有，买废船（G5.2 船市）是第三条路 |
| Q28 | 无主船的结构钢默认按回收价折现（开局要现金）；留料开关可打开；完整设备照旧卖 / 留 / 修 |
| Q29 | 开局几艘无主船免费；以后的无主船来自船市或拖船发现，付打捞 / 拖运费 |
| Q13 | 保留交易记账层（报价、预留、成交、托管、客户、存读档）；物流层（货运区小围栏 + 本地搬运车）重做 |
| Q7 | 日心开普勒轨道：太阳、火星、木星作参照，零压港 + 8–12 个小行星带站点都在真实轨道上；货船按霍曼 / 兰伯特转移，有 Δv、窗口、转移时间 |
| Q8/Q16 | 轨道与时间按真实算；到货压缩：近站约 1 分钟、远站约 6 分钟（现实时间），界面同时显示真实天数 |
| Q15 | 三家固定大公司在零压港贸易区有柜台（近、几十秒）；独立商户在小行星带各站（远） |
| Q17 | 运费：每单很小的固定手续费；Δv 与推进剂作为信息显示 |
| Q9 | 远处看星图（终端 / 交易行进入，站点在轨道上转，货船沿转移弧飞，点船看 Δv、到港时间、货物）；进入港区附近后世界里出现真实尺度货船，减速、靠泊货运区码头 |
| Q23 | 码头开局 1 个船位，货运区一阶 2、二阶 3；满了在港外排队，星图可见 |
| Q10/Q18 | 开局手动领货：货舱门开，货是真实物体，用抓钩拖进仓库收货口；超过 3 t 的大件用作业艇拖。修好货运区后普通货自动卸载，超大件 / 危险货仍需安排 |
| Q22/Q27 | 不去领：船一直等；只有下一艘船要靠这个船位时，船员才把货卸到码头空地腾位。空地上的货不算库存 |
| Q11/Q30 | 卖货对称：买家货船靠泊，开局你把货拖进它的货舱，修好货运区后自动装船；货船按轨道飞走，对方实收后付款 |
| Q14/Q24 | 加工区新建公司炉（同型号）与分选线（化验位随分选线），船坞熔炉只管拆船废料；取消“生产互斥” |
| Q32 | 货运区仓库 → 加工区：看得见的自动输送（轨道小车或皮带），预留后自己运 |
| Q31 | 仓库按实际库存画出货堆、托盘、钢坯垛（只画不做物理，不影响性能） |
| Q25 | 拆船时航运照常（船照飞、到港排队）、加工区照常运转；需要亲手的步骤（测温、出钢）停着等你；连续过程按真实时间算到你回来 |

## 我自己会定、不再问的细节（做时写进各步设计稿）
货船尺度按载货量 40–80 m；站点名称与轨道根数按真实小行星带分布（2.1–3.3 AU）取值；手续费数值、码头位置和输送线走向按现场布局定；所有台词只放占位 `Copy.say(radio, "L_xxx")`，由用户写。
