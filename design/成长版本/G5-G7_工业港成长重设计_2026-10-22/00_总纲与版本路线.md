# 《零压拆船厂》G5–G7 工业港成长重设计

日期：2026-10-22；更新：2026-10-23。状态：**玩法与外观基线已在 Q56 获用户确认，正推进 G5 开发；设计确认不代表功能完成或验收通过。**

依据：完整通读 V4 提案目录《对话.txt》1,885 行及四份整理稿后的修订。以用户原话为定位依据，区分用户明确要求、旧版承诺与助手新增建议，详见 [原始想法对照](06_原始想法对照与本轮修订.md)。保留现有 G4 物理作业、工程委托、仓库、港区建设和旧档权益。旧 G5/G6/G7 文件不覆盖。本目录描述后续目标；冲突处见第 8 节。人物对白与 KX-0 真相由用户创作。

文档优先级：V4 四稿与《对话》是需求来源和历史提案；本轮重新设计的建议开发顺序统一见本文件第 3、7 节与 04 第 9 节。V4-03 中 V4-A–F 的旧排期仅保留供追溯，不与本目录并列执行。它的产权、守恒、真实轨道和旧档保护要求继续保留。

## 1. 玩家长期想成为谁

用户明确定位：“以拆船起家的太空工业经营游戏”。玩家接手小行星带里一座普通、破旧的工业站，先靠自己拆船维持运转，再利用回收来的设备和经营所得，恢复加工、运输、能源与补给业务。玩家最终经营、驾驶载具穿行并亲手修复的整座工业港，是长期成长的成果；远航者是检验这套能力的一项重大工程。

成长体现在三个方面：
1. **判断更值钱**：知道买哪艘船、哪种报告可信、什么值得完整取下、哪笔订单值得接。
2. **已掌握的劳动越来越省心**：标准化工序由真实机器执行，玩家面对新结构、新风险和新规模。
3. **站体真的恢复功能**：修复后的设施有可见运动、物流、灯光、声音和服务，不只改结算倍率。

拆船保留最有特色的实际工程深度。其他区域也必须有自己的现场、业务、客户与收入，不能只给拆船加成。玩家可以始终专注拆船，也可以逐步转向加工、补给、资产交易或物流；各路线共用实际资产与成本。

### 整体体验的四条主线

- **在站内生活与工作**：紧凑的旧站、可用载具、可抵达的设备现场；修复后能看到、听到并使用新能力。
- **凭经验买卖资产**：从卖家声明、有限评分和自己的证据中判断，选船、提货、检验、转售或拆解。
- **把物质变成商品**：金属进真实加工设备，混合气经过净化、分离和液化，产品通过实际货运交付。
- **让产业共同运转**：发电、输电、储能、拖船、库容和设备相互影响；成熟工作自动化，玩家选择新机会与重大工程。

详细设计必须同时覆盖这四条主线。订单与账本负责连接它们，不能取代它们。

### 港站本体是必须交付的玩法

用户补充明确要求：建筑不能只有无碰撞的花纹，必须有实际载具；各区像公司业务一样发挥作用，美术与拆船同样硬核精细。近场实体几何、通道、碰撞、接口、机械和经营状态必须对应，六区与拆船按同尺度近景比较。具体规格见 [实体港站与工业美术验收](07_实体港站与工业美术验收.md)，约束从 G5 现场样片到 G7 的所有阶段。

## 2. 不变的底线

- 保留无人机、激光、抓钩、测量、气液回收、维修六个实际作业领域，不用菜单按钮替代现场的首次工程。
- 保留受托拆解与免费基础机；不凭空新增开局贷款，不因经营失误永久封死生涯。
- 自有出勤装备可损坏、遗失、找回；资格、已验收永久设施和工程记录不能因一次毁机清空。
- 工件真实切离、真实搬运、真实送到交付边界；不能在经营层假定它已经回收。
- 六区 ID 沿用 power / salvage / process / tug / trade / cargo，中央 ring 是汇合枢纽。
- 日常核心紧凑，巨型船坞向外扩展。ARK-01 仍约 600 m 整艘进入 620 m 级专用坞，禁止缩小或分段运入冒充。
- 不增加研究点、每日签到、强制职业锁、按完成单数硬拖时长。
- G 编号代表开发交付层，不代表玩家必须顺序刷完的章节。

## 3. 新版本结构

| 版本 | 玩家获得什么 | 必须形成的可玩闭环 | 不塞入本版的内容 |
|---|---|---|---|
| G4 遗留收尾（与 G5 并行） | 正确工序逐步交给机器，接受应急取货的结算代价 | 保留真实安全、交付、人工减少与问题清单；按最新用户要求不再以全绿卡住 G5 开工 | 不冒充全部验收或玩家评分已过 |
| G5.0 基础接通 | 原料、完整设备、现金去向清楚 | 真实回收→库存→出售/建设，旧账不重复 | 独立纯数据版本对外发布 |
| G5 现场前置样片 | 提早体验紧凑港站与载具 | 船坞、加工、动力、货运四处基础现场可往返；基础接驳与小艇驾驶/靠泊原型 | 等到 G6 后段才解决现有通行问题 |
| G5.1 第一笔工业订单 | 拆船开始有自己选择的目的 | 接需求→选船或购料→实际加工→发运收款 | 大规模市场波动 |
| G5.2 船市与提货 | 可以买船、识别信息、安排运输 | 固定船况→产权成交→拖运→待泊→实际入坞 | 复杂监管剧情、手动星际驾驶 |
| G5.3 工业港经营样片 | 受托、自购、外购原料三条路可比较 | 三条路完成同类需求，现场加工/装运与基础能源冲突可见，修复设施改变下一单 | 六区全部独立盈利 |
| G6.1 港站现场完整化 | 六区都值得走进、观察和操作 | 在 G5 现场样片上完善六区、载具用途、设备演出与原进度映射 | 只有工程台可交互的空壳港区 |
| G6.2 能源与排产 | 能同时做更多事 | 电网/储能/错峰/外包四种手段处理瓶颈 | 复杂反应堆操作模拟 |
| G6.3 气体与补给 | 回收气体成为完整可选产业 | 实抽→混合气入库→净化/分离→氧气液化与储运→过路船实际补给 | 所有气体全套低温工艺 |
| G6.4 六区产业经营 | 不亲自拆船也有可行生意 | 至少两条独立业务能盈利，成熟业务可自动履约 | 无人监管的无限挂机现金机 |
| G7.1 第二泊位 | 把成熟流程交机器，自己处理新问题 | 两个真实泊位共享设备与能源、异常接管 | 提前拿巨舰当并行测试器 |
| G7.2 重载港工程 | 能接以前无法处理的结构 | 大质量载荷、长期供货、重载坞修复 | 为开终局强制刷所有产业 |
| G7.3 远航者 | 用整个港口解决一次大型工程 | 消旋→危险核心→分阶段回收→重启转运环 | 偷换成数艘小船拼接结局 |
| G7.4 通关后 | 选择自己想经营的工业站 | 留存资产、特色业务、可重接工程挑战 | 无限价格膨胀、强制重置 |

G5.0 属于 G5.1 的底层工作，不能只做账本就宣称交付一版。G5 现场前置样片先解决短路线与基础载具，G6.1 扩展完整六区；两者共用同一套布局/交通系统。现有 G6 旧建设已经存在，不要求撤销；这里的 G6 指后续产业升级层。基础混合气检测、回收、储罐接口从 G5 现场设计预留，G6.3 的完整出口明确包含液氧补给，不能以“先卖混合气”永久替代。

## 4. 三层循环怎样相接

### 30 秒：手上有明确目标
看证据/读数→选择保留什么→安全操作→得到看得懂的反馈。切口、受力、温度、装卸、质量变化必须有现场依据。

### 一次游玩：完成一笔事
15–30 分钟的候选短会话：选需求→准备→执行关键工序→交付一批→决定收入或材料去向→看到下一项能力。时间仅是试玩目标，不是已测数据。

大型船和长航次可跨会话：保存的是实际项目进度，不要求一口气完成，也不要求玩家守着空闲倒计时。

### 多次游玩：改变经营能力
每个重要节点必须写出：旧限制、新方法、永久减少的重复劳动、开放的新生意、现场变化。只增加数字的节点不能作为主要成长奖励。

## 5. 前期体验重排

以下按“玩家遇见的事件”安排，时间是待真人验证的目标区间。不开局塞六区报表。

| 目标区间 | 玩家看到/做什么 | 下一次期待 |
|---|---|---|
| 首次短会话 | 独立教学船与基础安全作业；看见一项可用回收设备修复目标 | 留下一件关键设备，点亮自己的设施 |
| 首次成功交付后 | 出售或保留一件设备，两条路都能修复；给出差价与用途 | 下次能更完整、更省事地拆 |
| 随后 1–2 次会话 | 第一份明确数量的工业需求；可用受托回收或购买原料履约 | 第一次把废料变成自己需要的产品 |
| 熟悉基础作业后 | 少量船源和检验；可先受托、不要求立即承担购船风险 | 用自己的判断买下一艘熟悉船型 |
| 掌握一种工序后 | 工程成果与 G4 作业包接管重复部分 | 试新船、新结构，不重新拆同一套开关 |

成熟系统在新档中渐进介绍，不代表旧档玩家必须重做教程。高进度旧档可以直接使用已有能力；新教学采用可跳过提示。

## 6. 长期目标怎样产生

- **玩家钉选工程**：显示缺什么、从哪里来、能否采购/外包、修好以后能做什么。
- **买家提出需求**：订单说明数量、品质、交货方式、成本风险；玩家可以拒绝。
- **现场发现机会**：设备可用于某项工程、熟悉船型低价出现、现有余热/余电适合一笔订单。
- **设施暴露瓶颈**：先看到谁在等什么，再选储能、扩容、外包、错峰或换业务。
- **能力带来新规模**：更大整体吊装、更复杂危险系统、多客户交付、第二泊位、远航者。

结算最多突出三条建议：本单成果、已钉选目标的进度、下一次可尝试的方法。每条建议说明原因，可忽略、关闭，不弹无关广告。

## 7. 设计与实施边界

1. 当前 G4 完整船门槛未过，先修复和验收；本目录不授权以新系统绕开旧失败。
2. G5 第一条订单链可以复用受托船和外包运输，不等完整轨道市场才可验证。
3. 购买船的正式闭环必须有真实量纲的航次和到港流程，不能把临时直接生成留在正式版。
4. 紧凑站体的关键路线、基础接驳、小型作业艇驾驶与靠泊原型列入 G5 现场前置样片。完整六区美术可以递进制作，但正式经营样片不能让玩家继续长途慢飞去点同一张工程卡。
5. 不同时重写 game / career / plan / world。用小范围适配接入，每一阶段留下独立日志。
6. 本目录的数值均为候选平衡或测试目标；没有跑过的验收标“未验证”，没有真人反馈不声称动力问题已解决。

## 8. 与原稿的明确差异

| 原写法 | 本次重设计 |
|---|---|
| G5 排 G6 后，材料在下一单回港自动完成 | 旧 G6 建设保留；先用 G5 完成短经营链。生产跟随统一游戏钟及实际炉体，不按接单次数变出成品 |
| G5 气液按体积合成一个池 | 成分、质量、危险类别分开，气体商业处理在 G6.3 |
| 废料固定 1:0.7，加电子料炼工程合金 | 按原料化学/污染属性与工艺给产物、渣、去向；电子料不是通用炼钢添加剂 |
| 六区主要提供倍率 | 转为业务能力、吞吐、服务范围；旧权益有明确迁移，不叠乘刷钱 |
| 8–16 小时后才出现加工经营 | 第一笔真实需求与留货建设提前出现；完整产业以后扩展 |
| G7 第二泊位按同型整船全自动 | 优先执行经验证的局部作业包，保留授权、鲜活读数、结构检查和人工接管 |
| 终局 8–12 工作日 | 保留项目规模目标，工作日由工程推进产生；不要求等足天数或刷固定小单 |
