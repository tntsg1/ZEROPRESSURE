# 95 · 样板船 GR-7「灰鹭号」：可读链与第二种拆法（2026-10-28）

第三艘样板船，沿用 93 号 SA-200、94 号 OB-90 的做法：接单卡、作业状态牌和结算复盘连成一条可读链。

## 问答定案（10-28）
- **核心资产：** 推进总成 + 货舱货物，共 6 件，满价 $46,500：
  - 推进总成：ENG-C $11,000、ENG-F $5,000、T-F01 $6,500；
  - 货舱货物：C-01 $6,000、C-02 $11,000、C-03 $7,000。
- **两种拆法：** 保全拆 vs 暴力快拆。两种的预计收益和用时都用现有拆船机器人实跑得出（认真模式 / 粗暴模式），不凭估计。
- **力量感：** “加，克制地加”，所有船通用。

## 新做的
**核心资产模块（`scripts/core_asset.gd`）**
- **接单卡：** 两种拆法各写价钱、用时、风险。数字来自 `BOT_RUNS` 表，即机器人实测（见下）。
- **状态牌：** 每件设备一行，写分组、状态（完好 / 受损 N% / 切坏 / 已送走）和现在值多少钱。
  - 船上还有气压、燃料、电或运转中的发电机时，提示“船还没安全：先断电、泄压、放空再动刀”。
  - 列出最近 3 条损失，写明哪件设备、什么原因、多少钱。
- **复盘：**
  - 两组各写保住几件、值多少，以及已送设备口几件、船上还有几件；
  - 损失按原因汇总；
  - 说明多赚少赚的原因；
  - 给出“下次”建议。
- **损失原因：** 用游戏原有的设备损失记录（`game.devalued`），不另算。新增五种原因及建议：

  | 原因 | 来源 |
  |---|---|
  | 切坏 | dv_cut |
  | 撞伤 | dv_impact / fall / snap / tear |
  | 气瓶爆裂 | dv_burst / blowout |
  | 爆燃波及 | dv_blast |
  | 起火烧坏 | dv_fire |

**力量感（`scripts/game.gd on_body_freed`，所有船通用）**
- 一整块 ≥2 t 的结构脱落时：加真实重金属撞击声 `hull_break`（BluezoneCorp 大罐重击，Sonniss）。音量和音高随重量变化，并加一点额外震屏。
- ≥6 t 时再加 0.08 s 顿帧。小块不加。

**HUD**
- 状态牌标题太长时，金额换到下一行。GR-7 的“推进总成与货舱货物”原来会和金额叠在一起。

## 机器人实测（tests/bot_run.gd，paced，GR-001 原样，各跑一次）
| | 保全拆（认真模式） | 暴力快拆（粗暴模式） |
|---|---|---|
| 核心资产进设备口 | 6 / 6 件，$46,500 | 0 件，$0 |
| 用时 | 实际作业 17.3 分钟，钱在 18.6 分钟内全部到账 | 13.6 分钟 |
| 整船收入 | $123,758，回收率 98.9%，0 事故 | $14,774，罚款 $15,000，净亏 $9,226 |
| 事故 | 无 | 4 次舱室爆泄，两件强制回收件（G-01、BB-01）丢失 |

- 接单卡写的是：保全拆 ≈$46,500、约 17–19 分钟；暴力快拆 ≈$0、约 13–14 分钟。
- 风险说明后面附上实测的整船收入。
- 数字记在 `core_asset.gd` 的 `BOT_RUNS`。
- 认真模式最后剩下两根 8 m 长的线束 HAR-C1、HAR-C2 没有归置，跑到超时才停。这是机器人的问题，不影响核心资产，所以用时按收完钱的时间算。

**顺带修好机器人卡死（重要）**
- **现象：** 一开始两个模式都“卡住”，没有进度。
- **定位：** 用面包屑 + 看门狗线程定位到 `tests/salvage_bot.gd` 里“一次只往一个口送一块”的循环。
- **原因：** 它遍历的字典 `sent` 以车体为键，车体被接收口吞掉后对象就释放了。Godot 4.7 遍历这种字典会无限打转，一帧里转了 960 万次。
- **修法：** 先剔除已释放的键，再遍历键的副本。
- **后续：** 78 号 P0-1 里 M-14、RO-128、SV-122、SA-200 的机器人“超时”很可能也是这个原因，待复跑确认。

**设备送到哪里了**
- Piece 新增 `into` 字段：被接收口吞下时，记下是哪类口（equip / metal / hazard）。
- 状态牌和复盘据此区分：
  - 进设备口的，写“已送设备口”，照算钱；
  - 进熔炉的，写“进了熔炉”，按 0 算。
- 原来的 `world.tag()` 找不到已送走的件，复盘会少算件数；现在用 `_unit()` 记住每件设备。
