# 28 · 新手教程、引导与主线：访谈定案

日期：2026-10-24。来源：用户 grilling 四轮（Q1–Q21）。状态：**定案，待用户确认后开工**。每一步开工前仍写各自的设计稿。

## 用户原话要点
- “我刚进入游戏，就开始教我拆船，就是以前那种旧教程，旧教程加完之后，就直接开始拆一艘全新的船了，没有什么去小行星捞啊什么的。”
- “打开终端里面也很复杂，正常的玩家新手是看不懂的。”
- “最好还要有一个下一项任务中主线的引导，这样才能让玩家知道应该要去哪。”

## 定案
| 编号 | 决定 |
|---|---|
| Q1 A | 27 号现场任务引导先收尾（修测试夹具、跑完验收、截图）再做下面的事 |
| Q2 B / Q9 B / Q10 B / Q14 A / Q15 A | 加一张**经营补贴训练单**：在真实船坞里做，港务局送 1 t 未分选金属、本单电费与化验费全免，按分选 → 化验 → 炉台出钢 → 交给工业客户走一遍，引导全程带着，客户货款归玩家；开市场后固定挂在终端待决策第一条，没做完时隐藏其他生产类事项（拆船合同、修缮、建设照常）；等加工区搬家后做 |
| Q3 A | 交易行里翻页的“经营开工指引”删掉，换成“按我现在的库存带我做下一步”按钮（启动引导） |
| Q4 全选 | 现场引导覆盖：船坞修缮、零压港建设、作业艇与接驳车、交易行买卖与挂单、留料开关、航运领货（领货随航运一起做） |
| Q5 C | 小行星带序章做出来后，新档直接进序章（基础操作边做边教），TS-1 九课改成可选的训练舱；专项资质课不变 |
| Q7 A / Q13 A | 序章之前先做**开场拖船过场**：新档第一艘船（TUG-001）进坞前 10–15 秒，你的拖船在小行星带找到漂流船、挂缆、拖回七号坞，可 Esc 跳过，只放一次；以后无主漂流船入坞时拖船动画开头加一句“从小行星带拖回”字幕 |
| Q8 A / Q12 | **终端逐步开放**（旧存档全开）：新档开始只有合同、资金；第一次有零件或第一单结束 → 船坞修缮；第一单结算 → 账本、贷款、每单应付；第一次拿到声望 → 声望、目标条；市场开放 → 交易行、成长与建设、四格状态、待决策；第一次遇到需要资质的船 → 训练舱；工具技术、消耗品、无线电第一次用到时。每次点亮配一句说明 |
| Q16 C | **主线**：固定章节 + 章内步骤按实际状态算。章节草案：拆完开局三艘漂流船 → 修好照明与配电 → 修好熔炉主火和碎屑网 → 修好贸易港一阶、开市场 → 做完经营训练单、拿到第一笔钢坯货款 → 修好加工区、货运区 → 船坞扩到 88 m → 修好动力区、拖船站 → 转运环重启 → 远航者 |
| Q17 C | 主线在空船坞时 HUD 常驻一行（拆船时不显示），终端首页顶上的“下一个目标”条改为显示主线 |
| Q18 | “带我去”四种：要去某处 → 现场任务引导；要接某种合同找零件 → 打开合同页并标出有这种零件的船；钱够了要修 → 打开修缮页或成长页并选好；在等 → 只显示进度 |
| Q19 A | 主线和玩家自己钉选的目标并存，互不覆盖（没有定关闭开关，先不做） |
| Q20 A | 章节名和每步功能说明由我写成简短界面文字；每章开始和结束时梁工的话只放占位，由用户写 |
| Q11 A / Q21 A | 开场过场、终端逐步开放、主线在 27 号收尾后马上做（与加工区无关）；经营那几章的步骤和训练单等加工区搬家后补 |
| Q6 | 大顺序：27 收尾 → 新手三件（过场、终端逐步开放、主线）→ 加工区搬家（+ 补贴训练单）→ 轨道航运（+ 领货引导）→ 小行星带序章（TS-1 改可选）→ 船市（G5.2）。注意与 23 号原定“航运在搬家前”相反，用户已确认 |
