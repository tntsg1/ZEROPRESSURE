# 103 号 终端统一重画（2026-10-28）

## 用户原话
截图：轧机操作台、业务终端的名字压在屏幕上，右边那个还出了画面。“优化终端”。

## 盘问定案
| 题 | 定案 |
|---|---|
| Q1 范围 | A：6 个区的业务终端（含港心）+ 轧机操作台，统一一套画法 |
| Q2 外形 | A：落地式工业控制台 |
| Q3 屏幕 | A：屏幕显示该区实时摘要，另加悬停卡（用途 / 现在 / 你能做） |
| Q4 名字与靠近提示 | A：名字牌固定在台子上方，不压屏、不出画面；靠近时亮出按键提示，台下地面亮起一条光带 |

Jev 不适用：外观方向，由用户逐题定。

## 做法（`scripts/console_art.gd`）
- **台体**：一次建成网格，立柱按到地面的距离各建一份。从下往上依次是：
  - 地脚板和地脚螺栓、立柱，一根线缆从柜子背后接进地面；
  - 柜子：门缝、百叶、把手；
  - 斜面操作板：两排按键、两盏指示灯（本区状态、电源）、红色急停；
  - 屏幕壳和遮光檐。
- **屏幕**
  - 摘要：

    | 终端 | 屏幕显示 |
    |---|---|
    | 动力区 | MW / 容量、负荷和频率、岸电，带负荷条 |
    | 贸易港 | 客人数、交货中的笔数 |
    | 货运区 | 库存吨数、叉车任务数 |
    | 拖船站 | 拖船数、充电数 |
    | 加工区 | 炉况、轧机状态 |
    | 港心 | 已修几个区、现金，带进度条 |
    | 轧机操作台 | 轧机状态（和轧机灯同源） |

  - 文字按屏幕像素绘制；太远看不清时改画几条亮条。
  - 无人机在台前时，屏幕更亮。
- **名字牌**
  - 以屏幕像素固定大小，居中在遮光檐上方，不会压到屏幕；
  - 会被限制在画面内，但只在终端本身在画面里时才画；画面外的终端不画名字牌，不会钉在屏幕边上；
  - 靠近时名字下面加一行“[E] 打开…”。
- **靠近反馈**：原来漂浮的圆环去掉，改成台下地面一条脉动的光带，上方有渐隐的光晕。
- **悬停卡**：每个区的业务终端一张，接在 `district_interiors.gd` 的设施卡上，内容是“用途 / 现在 / 你能做”。轧机操作台的卡归加工区会话的 `process_art.gd`，它原来就有轧机卡。

## 改动的文件
- 新增 `scripts/console_art.gd`。
- `port_structure.gd`：`_console()` 改为调用它。
- `mill_line.gd`：只改了操作台那一段画法，改前已通知加工区会话。
- `district_interiors.gd`：设施卡列表末尾追加本区终端卡，各区分支不变。

## 测试
- `tests/console_probe.gd`（有画面）：每个区拍三张（远景、台前点亮、终端在画面边缘），外加轧机操作台近景。
- 回归测试全部通过：`port_walk_check` 44、`mill_check` 26、`interiors_check` 25、`console_check`。
- 已知：探针把镜头拉得极近（缩放约 30 倍）时，加工区自己的代码会报 “p_size <= 0”（字号为 0）。正常缩放下不报，不是终端画法引起的，已转告加工区会话。
