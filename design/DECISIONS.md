# 零压拆船厂 / ZERO PRESSURE — Demo 定案（grilling，2026-10-15）

来源：Google 文档《零压拆船厂 / ZERO PRESSURE》（v1 爽快拆解 + v2 硬核诊断）。用户原话：极简主义、极其优秀、极其精美；**动画绝对不能少，绝对不能拖**；策划案可参考，不必照做。动画参考《共振》《天穹防线》。

## 1. 方向与规模
- **核心**：拆解手感与动画为主体 + 轻量"测了才知道"（未测显示 `?`；保留"测错位置"诊断陷阱）。首通目标 20–30 分钟。
- **规模**：完整 GR-7「灰鹭号」42 m 货船，六舱 A–F + 骨架，约 45 个可拆件，带结算。无升级、无第二艘船。
- **结算后**：评级 70 / 80 / 92%，可重开同一艘船刷最佳回收率（事故位置固定）。可提前结束合同。
- **平台**：Windows exe，1920×1080，可全屏。网页版以后再说。
- **存档**：合同中途自动存档，可续（含切割后的碎块多边形）。

## 2. 画面
- 纯 2D 横向剖面。近黑底 + 白色几何线稿 + **唯一强调色：切割热橙 `#FF5A1F`**（激光、高温、警示）。
- 电 / 压力 / 流体各一个低饱和辅助色，只在测量和事故时出现；平时全黑白。
- 背景极简：船坞框架线 + 稀疏星点。
- 出厂图纸叠加层（Tab）：虚线蓝图样式，显示设计布局、接口编号、管线走向，**不保证与现状一致**（例：一个货柜实际已移位）。拆开外壳后实物从虚线位置"显影"。
- 拆开前只能看到外壳；不透视。

## 3. 操作者与镜头
- 玩家 **WASD 驾驶一架遥控无人机**（极简白色几何机体，热橙喷口火舌）。
- **强真空惯性**：松手继续滑，必须反向喷气刹车。`Shift` 冲刺（拉伸拖尾）。`Space` 全向反推刹停（多喷口同时喷）。
- **抓货质量叠加**：拖重物时无人机明显变笨重，转向/刹车更难，货物反拽无人机。
- 镜头**丝滑运镜，紧贴无人机**（沉浸感），缩放时略微超前；拆大件时轻微冲击反馈；终局一镜拉远。
- 无人机耐久 100：电弧 −40、喷流直击 −25、高速撞结构 −10。归零 → 炸成碎片，2 秒后新机从发射口弹射进场，扣 $2,000，手上的零件脱手漂走。回船坞免费补满。

## 4. 工具（策划原样五件，`1–5` 切换）
1. **测量**：探针接触测点得读数（压力/电压/温度/流体存量）。读数快速滚动后稳定，`?` 翻成数值。
2. **激光切割**：**自由切割**。按住左键，激光从无人机射向光标，熔切前沿按材料厚度限速追赶光标轨迹，走太快会落后；松手只算已切透部分。作用距离约 4 m。**一切都能切**，但光标碰到设备/货柜时激光自动暂停，再按一次确认才切入。
3. **磁力抓钩**：3 吨上限；超重时牵引光束拉满、颤抖、报警。**可拖可甩**：松开时零件保留速度，回收口有吸引场自动捕获；甩偏会撞坏东西或飘远。
4. **维护工具**：拧螺栓、开关阀门、拔插头、解锁扣——完整保留零件价值。
5. **气液回收**：软管接外部接口，抽气 / 抽液到船坞储罐（慢但值钱）或直排真空（快但损失回收价值）。长过程不阻塞，可同时去拆别处。

飞船原有开关（主电源、舱门、阀门）直接点设备本身操作。右键 = 松开抓钩 / 取消。滚轮微调镜头。Esc 菜单。不做手柄。

## 5. 测量与知识
- 剖面上贴读数标签：已测 / 待测 / 过期 三态；**悬停**显示仪器、测点、测量时间。无单独记录面板。
- **读数会过期**：改变相关系统后（重新接电、开阀、拆开舱壁等），旧读数变灰划线。
- 真实状态（ActualState）与已知状态（KnownState）分离；测点读到的是它实际连通的容积。

## 6. 危险（七种全放，全部可提前测出，无随机惩罚）
1. 货舱 108 kPa + **测错陷阱**：P-C01 读 0.0 kPa 是隔离阀 V-C01 关闭外侧；开阀复测 108.1 kPa。不抽气就切壳 → 定向喷流，货柜被推撞。
2. 电力舱终端显示 OFF，但蓄电池 B-01、电容 C-01 仍带电，须分别断开与放电；带电切割 → 电弧 + 白闪 + 设备报废。
3. 生活舱抽空了，但两个储气罐独立带压。
4. 推进剂储罐 35%，未抽空就切 → 泄漏 + 危险区。
5. 维修舱冷却管残液 + 高温：关两侧阀、抽液、等冷却。
6. 漏解的线缆 / 锁扣：拖拽时绷紧颤动，最终扯断，零件折价。
7. 抓钩拖太快 / 甩偏：撞击按冲击力折价。

## 7. 经济与回收
- **三个回收口**：金属熔炉（熔化动画）、设备回收（扫描入库）、危险品（封罐）；投错口折价。气体单独储罐。
- 外壳 / 框架 / 龙骨按重量算废金属价，**切割不折价**。设备、货柜被激光切到一刀即跌为废料价（如导航电脑 $6,000 → $300）。
- 小于 0.1 t 的碎块变碎屑，由船坞收集网自动吸走（吸入拖尾），按废金属价入账。
- 零件表（总值 $120,000，合同费用 $9,000，完美净利 $111,000）：
  - A 驾驶舱：导航电脑、黑匣子（强制回收）、控制台、3 块外壳
  - B 生活舱：2 储气罐、环境控制单元、家具、2 块外壳
  - C 货舱：货柜 C-01 2.4 t / C-02 1.7 t / C-03 1.2 t（各 4 锁扣，C-03 另有电源与冷却接头）、吊装轨道、4 块外壳；外舱门变形卡滞
  - D 电力舱：G-01 主电源（强制回收）、蓄电池、电容、配电柜
  - E 维修舱：冷却泵（完好，仅出口管断）、散热器、破损管道（废料）
  - F 推进区：2 辅助推进器、主发动机三段（中央 4.6 t 超重，需拆分）、推进剂储罐
  - 骨架：主龙骨 4 段 + 4 个船坞夹具（最后解除）

## 11. 实现中补充的决定（2026-10-15，开发时按定案自行决定）
- 世界是 2D 横剖面（像剖开的模型）：外壳是剖面上的一圈板带，舱室内部在未打开前是暗的；所有工具"作用于光标处"，不能伸进未打开的舱室。
- 未测量时不显示任何压力/电压；读数以标签贴在测点旁，悬停看仪器、测点、时间。
- 气压：0.1 m 网格判定舱室之间、舱室与真空的开口大小（后台线程计算），按压差交换气体；切开带压舱室 → 爆发性失压事件（易碎设备受损、零件被吹走、喷流推无人机）。
- 电力：G-01 远程停机指令「已发送」但实际不停（陷阱）；K-G / K-B 在 D 舱顶外侧面板；电容需接 E-D02 受控放电（母线仍有电源时放电装置跳开）；G-01 本地停机需打开 D 舱。
- 冷却回路温度跟随发电机，发电机停后约 15 s 降到 60 °C 以下才能拆管接头。
- 数值：外壳 1.6 t/m²（单块 1.5–2.2 t），龙骨每段 5–7 t、吊装轨道 4.5 t、推进区纵梁 3.3 t（都要切）；中央推进组件 2.6 t + 两块护罩各 1.0 t。
- 机器人全流程验证：规程拆解 99.9% / 净收益 $110,910（策划案完美值 $111,000）；全部扔熔炉 14.2% / 未达标。
- 船坞（用户 2026-10-15 要求）：**半开放**，不是封闭方框。底部平台（支腿伸进黑暗）、左侧塔架（机库）、塔架伸出的悬臂（挂设备回收口和两根软管桅杆），第三根桅杆是平台上的立柱；上方和右侧敞开，边缘是看不见的牵引场（有东西靠上去时局部发光、角上有信标）。背景：视差星空 + 下方远处的行星弧。
- 配乐：用户 Suno 曲目，Vacuum Salvage 做主循环，The Final Chord 在结算时淡入。

# 合同循环 v2 定案（grilling，2026-10-15）

用户方向：以后会加别的飞船，现在先把灰鹭号打磨好。

## 结构
- **无尽合同**（Q1 A）。每拆完一单回到**船坞终端**（Q7 A / Q21 A），从 **3 份报价**里挑 1 份，报价不能花钱刷新。
- **新档第一单固定**为现在手工设计的灰鹭号（教学关），之后随机（Q20 A）。
- **声望等级**（Q8 A）：评级越高声望越高，高声望解锁更危险、报酬更高的报价（同时 2–3 个招牌陷阱）；三份报价里始终保留一份低风险单。等级：见习 → 认证 → 资深 → 首席。

## 变体（Q2 B，Q3 1–4）
- 参数随机 + 每单保底一个从陷阱池抽取的**招牌陷阱**。
- 会变：危险配置（各舱压力、电源、推进剂/冷却液、泄漏点）、货物（数量/位置/内容/货值）、事故破损、图纸偏差。船体结构不变。
- **陷阱池 10 种全要**（Q11）：测错阀门、假停机、隐藏储罐、带电货柜、焊死的舱门、管线改道、第二电源（应急发电机）、结构暗伤、易爆货物、消防系统储压。前几单只抽直观的，声望高了才出现管线改道/第二电源/结构暗伤这类。全部可以靠测量和观察提前发现。

## 钱
- **报价卡**（Q9 B）：报酬（合同费 + 预估可回收总值）、风险星级、2–3 行船载记录和货物清单（记录可能过时或错误）。
- **先付合同费**买拆解权，收入全靠回收；高风险单合同费相对便宜（Q16 A）。
- **软时限**（Q4 B / Q13 A）：每单有标准用时；在标准用时内完成 +20% 净利，超时线性降低，到 2 倍标准用时为 0。结算多一行“时效奖金”。
- **贷款**（Q5 C / Q10 B / Q15 A）：开局欠 30 万；每单结算强制扣 2 万分期 + 未还本金 2% 利息；不够扣的差额并回贷款继续计息；终端里可以额外提前还；还清时里程碑演出“BERTH 07 归你了”，以后新船型挂在这个里程碑上解锁。

## 升级商店（Q6 全要，Q14 A）
- **工具**（每项 3 级，约 2 万 / 5 万 / 12 万）：切割速度、抓钩容量（3 → 5 → 8 t）与牵引距离、软管泵速、远程测量、扳手速度。
- **无人机**（每项 3 级）：耐久、推力、冲刺、拖重物时的稳定推力。
- **船坞设施**（8–20 万）：
  - 自动拖运臂（Q18 A）：挂在悬臂上，只抓漂浮的废金属送熔炉，不碰完整设备；初级 6.5 万（慢、1 t 以内），升级提高速度和吨位。
  - 第二架无人机（20 万，Q17 A）：搬运无人机，玩家给漂浮零件打标记并指定回收口，它自动去抓、拖、送。
  - 更多软管桅杆。
  - 价值分析扫描：悬停显示零件估值。
- **消耗品**（3,000–15,000，Q12）：维修包（现场 +50 耐久）、爆破切割环（贴在厚龙骨上瞬间切开一圈，大爆闪）、备用无人机（损毁免费重生）、情报包（接单前揭示一项隐藏状态的真实数据）。
- 全部买齐约 15–20 单。
- **升级看得见**（Q19 A）：激光变粗变白热、抓钩发射器变大且光束 3 股 → 5 股、无人机加装甲板和喷口、船坞设施直接出现在泊位上。

## 终端与存档
- 终端全屏，**三个标签页**（2026-10-15 改）：「合同市场」（3 张报价卡：船型、长度、报废原因、预估可回收价值、合同条件、风险标记，剖面缩略图只画货单/记录提到的东西）·「设备商店」（工具 / 无人机 / 消耗品）·「船坞管理」（工作区、维护设施、扩建：拖运臂、第二架无人机、软管桅杆、价值分析扫描，后期重型吊机与泊位扩建）；资金、贷款、分期、声望放在顶部常驻栏；底部“接单”；接单后镜头推进船坞，拖船送船约 3 秒，可跳过。买升级时对应部件在无人机/船坞示意图上拆装换新。
- 生涯存档：资金、贷款、声望、升级、库存；合同中途照旧可存。标题画面“继续生涯 / 新生涯”，新生涯二次确认、旧生涯备份（Q22 A）。

## 阶段三实施中自己定的（2026-10-17，用户说「期间你自己琢磨」；都可以改）
- **合同价值里危险品只算四成**：爆炸物只能进危险品口，那里只付四成，所以验证器和变体生成器算合同总价时按四成算（吊舱总价因此是 $51,100，不是 $55,900），否则完美拆也到不了 A。
- **作业方案的比对规则是「不比当时更危险」**：做方案时某个测点读的是没压力 / 没电 / 没液体 / 没磁场，重放时也必须是；当时有、现在没有不算异常（舱室抽气中途读到的 9.5 kPa、现在 2 kPa 这种不该挡住方案）。
